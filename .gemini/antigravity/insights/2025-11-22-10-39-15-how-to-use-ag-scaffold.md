# How-To: Use /ag-scaffold-issue

## Purpose
To quickly set up the standard directory structure for a new GitHub Issue, ensuring compliance with IDD standards.

## Steps
1.  **Identify Issue**: Have the Issue ID and Title ready.
2.  **Run Command**: Type `/ag-scaffold-issue` in the chat.
3.  **Provide Input**:
    *   **Issue ID**: Enter the number (e.g., `24`).
    *   **Title**: Enter a short, descriptive title (e.g., `fix-login-bug`).
4.  **Verify**: Check `docs/idd/issues/issue-24-fix-login-bug/` to see the created folders and files.
5.  **Start Work**: Open `step-51-to-do/issue-24-to-do.md` and start checking off items.
