## Demo Preparation

### Demo Script

**Part 1: Create an Issue (30 seconds)**
```bash
# Navigate to GitHub
open https://github.com/your-org/your-repo/issues/new

# Fill out issue template
Title: "Add user profile page"
Type: Feature Request
Description: "Users should be able to view their profile"
Labels: enhancement, user-facing

# Submit
```

**Part 2: Watch It Sync (30 seconds)**
```bash
# Wait for workflow to run (or trigger manually)
gh workflow run sync-issues-to-todo.yml

# Show TO-DO.md
cat TO-DO.md

# Point out the new issue appears automatically
```

**Part 3: Make Some Changes (60 seconds)**
```bash
# Create feature branch
git checkout -b feature/user-profile

# Make changes
echo "// User profile code" > src/profile.js

# Commit with issue reference
git add .
git commit -m "feat: add user profile page (#42)"
```

**Part 4: Capture Session (30 seconds)**
```bash
# Capture session for AI
python3 bin/capture-session.py

# Show context file
cat .ai/context.json | jq '.commits[-1]'

# Explain how AI can use this
```

**Part 5: Create PR and Merge (60 seconds)**
```bash
# Push branch
git push -u origin feature/user-profile

# Create PR
gh pr create --fill

# Show PR validation
# Merge PR
gh pr merge --squash

# Show issue auto-closes
```

### Demo Environment Setup

```bash
# Prepare clean demo repository
git clone https://github.com/your-org/demo-repo
cd demo-repo

# Ensure workflows are enabled
gh workflow enable --all

# Create some example issues
gh issue create --title "Example Bug" --body "Demo issue" --label bug
gh issue create --title "Example Feature" --body "Demo issue" --label enhancement

# Sync once to populate TO-DO.md
gh workflow run sync-issues-to-todo.yml

# Open in editor
code .

# Open in browser
open https://github.com/your-org/demo-repo

# Ready to demo!
```

### Common Demo Pitfalls

**Avoid:**
- ❌ Relying on live internet (have backup screenshots)
- ❌ Using real project (create clean demo repo)
- ❌ Assuming workflows run instantly (pre-run or explain delay)
- ❌ Trying to show everything (focus on top 3 features)
- ❌ Not testing beforehand (dry run at least twice)

**Do:**
- ✅ Have screenshots as backup
- ✅ Use demo repository
- ✅ Pre-trigger workflows or show logs
- ✅ Focus on most impactful features
- ✅ Test everything multiple times
