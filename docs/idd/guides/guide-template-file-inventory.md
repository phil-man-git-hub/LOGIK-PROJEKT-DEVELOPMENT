## Extraction Script

Here's a complete script to extract all files:

```bash
#!/bin/bash
# extract-idd-template.sh

set -e

SOURCE_REPO="."
TEMPLATE_DIR="github-idd-template"

echo "Creating template structure..."
mkdir -p "$TEMPLATE_DIR"/{.github/{ISSUE_TEMPLATE,workflows},bin,docs/{idd,examples},config,.ai-context/{sessions,search_index,context_snapshots,insights}}

echo "Copying GitHub configuration..."
cp .github/ISSUE_TEMPLATE/*.yml "$TEMPLATE_DIR/.github/ISSUE_TEMPLATE/"
cp .github/PULL_REQUEST_TEMPLATE.md "$TEMPLATE_DIR/.github/"
cp .github/workflows/*.yml "$TEMPLATE_DIR/.github/workflows/"

echo "Copying Python scripts..."
cp bin/*.py "$TEMPLATE_DIR/bin/"
cp requirements.txt "$TEMPLATE_DIR/"

echo "Copying setup and configuration..."
cp bin/setup-idd.sh "$TEMPLATE_DIR/bin/"
chmod +x "$TEMPLATE_DIR/bin/setup-idd.sh"
cp config/idd-config.template.yml "$TEMPLATE_DIR/config/"

echo "Copying AI context..."
cp .ai-context/README.md "$TEMPLATE_DIR/.ai-context/"
touch "$TEMPLATE_DIR/.ai-context"/{sessions,search_index,context_snapshots,insights}/.gitkeep

echo "Copying documentation..."
cp -r docs/idd/ "$TEMPLATE_DIR/docs/"

echo "Copying supporting files..."
cp .gitignore "$TEMPLATE_DIR/"
cp LICENSE "$TEMPLATE_DIR/"

echo "Creating template README..."
cp docs/idd/TEMPLATE_README.md "$TEMPLATE_DIR/README.md"

echo "✅ Template extracted to: $TEMPLATE_DIR"
echo "📦 Total files: $(find "$TEMPLATE_DIR" -type f | wc -l)"
echo "📊 Total lines: $(find "$TEMPLATE_DIR" -type f -name "*.py" -o -name "*.yml" -o -name "*.md" | xargs wc -l | tail -1)"
```

## Parameterization Map

### Values to Replace

| Placeholder | Example Value | Used In |
|-------------|---------------|---------|
| `${PROJECT_NAME}` | "Your Project" | Config, docs |
| `${REPOSITORY}` | "owner/repo" | Config, scripts |
| `${REPO_OWNER}` | "owner" | Workflows |
| `${REPO_NAME}` | "repo" | Workflows |
| `${MAIN_BRANCH}` | "main" | Config, workflows |
| `${TODO_FILE}` | "TO-DO.md" | Scripts, workflows |
| `${LABELS}` | ["enhancement"] | Config, workflows |

### Configuration Variables

All configuration is centralized in `idd-config.yml`:

```yaml
project:
  name: ${PROJECT_NAME}
  repository: ${REPOSITORY}
  
files:
  todo_file: ${TODO_FILE}
  
labels:
  track: ${LABELS}
```
