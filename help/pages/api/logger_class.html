Logging & Diagnostics API

LOGIK-PROJEKT uses a multi-layered logging system designed for both human review and automated AI diagnostics.

LogTransmitterHandler

The LogTransmitterHandler is a specialized logging.Handler that broadcasts log records as JSON over UDP. It is used to provide real-time telemetry to external listeners.

Constructor

def __init__(self, host='127.0.0.1', port=54322):
  • host: The target address for the UDP broadcast (default: localhost).
  • port: The target UDP port (default: 54322).

Data Format

The handler broadcasts a JSON object for each log record:

{
    "timestamp": "2026-02-08T12:34:56.789",
    "level": "INFO",
    "module": "app",
    "function": "main",
    "line": 42,
    "message": "Application started successfully."
}

Threaded Logging

For UI operations, the project leverages threaded_logging_utils.py to ensure that logging from background worker threads does not block the main Qt event loop.

Best Practice: Always use the root logger (logging.getLogger(__name__)) within modules to ensure that logs are correctly routed through the attached handlers (File, Console, and Transmitter).
