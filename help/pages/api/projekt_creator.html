ProjektCreator Class

The ProjektCreator class is responsible for the technical execution of project creation. It handles the generation of directories, symbolic links, startup scripts, and Wiretap nodes required for a functional Flame environment.

Methods

create_projekt

def create_projekt(self, config: ProjektParameters):

Executes the full project creation sequence. This is a multi-step process that includes:

  1. Environment Setup: Validates user and system information.
  2. Directory Scaffolding: Creates the folder hierarchy on the filesystem based on the selected template.
  3. Flame Integration: Generates and exports the project XML for Flame's Wiretap server.
  4. Asset Management: Copies presets, Python scripts, and bookmarks into the project structure.
  5. Automation: Generates launcher aliases, backup scripts, and archive utilities.
  6. Database: Initializes a project-specific PostgreSQL database.

Data Model

The creator relies on the ProjektParameters data model, which encapsulates all technical details such as resolution, frame rate, cache formats, and storage paths.

Implementation Detail: This class leverages subprocess to interact with system-level commands and Flame utilities like startFlame.
