RAG & MCP Systems

LOGIK-PROJEKT includes an integrated Retrieval-Augmented Generation (RAG) knowledge base and a Model Context Protocol (MCP) server to facilitate AI-assisted development and semantic code search.

RAG Manager

The RAGManager orchestrates the indexing and querying of the repository context.

from api.core.rag.rag_manager import RAGManager

manager = RAGManager()
# Perform semantic search
context = manager.query_context("How are Flame bookmarks created?")

MCP Tools

The MCP server exposes several tools that can be used by LLMs to interact with the project.

  • query_project_knowledge: Performs a semantic search across all indexed files.
  • get_project_status: Returns the content of the project's TO-DO.md file.
  • list_recent_sessions: Lists recent development session summaries from the Antigravity knowledge base.
  • listen_to_live_logs: Captures a 5-second burst of live application telemetry.

Deployment

Start the MCP server in the background to allow external AI clients to connect:

./scripts/logik_projekt_mcp.py --transport sse --port 54321 --background
Endpoint: Once running, the server is available at http://localhost:54321/sse.
