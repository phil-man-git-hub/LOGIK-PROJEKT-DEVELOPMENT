Application Interface & Process Flow

The LOGIK-PROJEKT 2026.2 interface is designed for high-efficiency project creation. It is divided into two primary columns: Template Configuration (Left) and Deployment Settings (Right).

1. Template Info & Parameters

Define the core metadata (Serial Number, Client, Campaign) and technical specifications (Resolution, Framerate, OCIO) for your project template.

2. Template Management

Use the Export and Import buttons to save your configurations or load existing templates from your studio's library.

3. Flame Options

Configure Autodesk Flame-specific paths and software versions. The application automatically detects installed Flame versions.

4. Projekt Summary & Creation

Review the final project parameters and paths. Click Create LOGIK-PROJEKT to execute the full deployment sequence.

5. Shell Output (Telemetry)

Monitor the creation process in real-time. This area displays the same data broadcast to the Live Diagnostics bridge.

Process Flow Summary

  1. Initialize: App loads defaults and connects the UDP Log Transmitter.
  2. Configure: User inputs template data or imports a JSON template.
  3. Consolidate: AppLogic combines Template and Flame data into a ProjektParameters model.
  4. Execute: A background Worker Thread runs the ProjektCreator to build the filesystem and Flame nodes.
  5. Notify: Status is updated in the Shell Output and broadcast to diagnostic listeners.
Pro Tip: All fields marked with (Optional) can be left blank if you wish to use the application defaults or omit those metadata tags from your project.
