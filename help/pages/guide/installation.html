Installation Guide

System Requirements

  • Workstation: Linux (Rocky Linux 9.5 recommended) or macOS (Sonoma 15+).
  • DCC: Autodesk Flame 2026+.
  • Storage: A root-level mount point at /PROJEKTS.

1. Workspace Preparation

Create a directory for your development projects and clone the repository:

mkdir -p ~/workspace/GitHub/
cd ~/workspace/GitHub/
git clone git@github.com:flamelogik/LOGIK-PROJEKT.git
cd LOGIK-PROJEKT

2. Python Environment

LOGIK-PROJEKT leverages a Python 3.13.3 environment. Run the setup script to create the local virtual environment:

./bin/setup-venv-3.13.3.sh

Once created, activate the environment and install dependencies:

source .venv3.13.3/bin/activate
pip install -r requirements.txt

3. Flame Integration

To ensure LOGIK-PROJEKT can interact with your local Flame installation, establish the path to the Flame Python interpreter:

install/get_current_adsk_python.sh

4. Creating Desktop Launchers

Generate the appropriate application bundles or desktop shortcuts for your OS:

install/create_desktop_apps.sh
macOS Tip: After running the install scripts, you can find LOGIK-PROJEKT.app in your project root.
