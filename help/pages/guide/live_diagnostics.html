Live Diagnostics

LOGIK-PROJEKT features a real-time telemetry bridge that broadcasts application logs over UDP. This allows developers and AI agents to monitor the application's internal state as it runs.

Log Transmitter

The LogTransmitterHandler is a custom logging handler integrated into src/app.py. It automatically intercepts all log records and broadcasts them as JSON packets to localhost:54322.

Using the Debug Listener

You can view the live diagnostic stream by running the provided listener utility:

./scripts/logik_debug_listener.py

This will display formatted logs in your terminal, including the timestamp, log level, module name, and message.

AI Interaction

The MCP server includes a tool called listen_to_live_logs. An AI agent can invoke this tool to "listen" to the application for a specified duration (defaulting to 5 seconds) and receive the captured logs as text. This is extremely useful for automated debugging.

Performance: The transmitter uses UDP ("fire-and-forget"), ensuring that the diagnostic stream has zero impact on the responsiveness of the LOGIK-PROJEKT user interface.
